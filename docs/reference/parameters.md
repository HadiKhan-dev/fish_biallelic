# Parameter reference

Generated by `python docs/generate_references.py` from every `*parameters.py` module. Defaults below are **Python source expressions**; named factories refer to their own tables. Expressions preserve exact arithmetic and provenance without importing science or running kernels.

These internal model constants are not extra TOML settings. Only keys in the [settings reference](settings.md) are user settings. Module constants may also express dimension-only workspace limits; their source provenance distinguishes them from scientific parameters.
