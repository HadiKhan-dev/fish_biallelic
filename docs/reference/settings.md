# Settings reference

Generated by `python docs/generate_references.py`; edit the schema, then regenerate.

Defaults < preset < TOML < command-line options < repeated `--set` overrides. Paths resolve against the invocation's working directory. Unknown settings and invalid values fail before execution.

Empty strings represent an unset optional value. A default is not necessarily a complete runnable configuration. Scientific settings enter the relevant derivation; operational fields are identified below. Pairwise IBD is an output selection and is off by default.

## Presets

A preset supplies settings; it does not read pedigree metadata.

### tromau

```toml
# TroMau cross (AcTm BCF): the 22 autosomes. Every sample of the BCF is analysed and is a candidate parent of every
# other (no sample metadata is read). The data path ([input] vcf) comes from the user's configuration.
[input]
kind = "vcf"
contigs = ["chr1", "chr2", "chr3", "chr4", "chr5", "chr6", "chr7", "chr8", "chr9", "chr10", "chr11", "chr12",
           "chr13", "chr14", "chr15", "chr16", "chr17", "chr18", "chr19", "chr20", "chr22", "chr23"]
```

### generic

```toml
# Generic indexed VCF/BCF. The user supplies the contigs explicitly.
[input]
kind = "vcf"
contigs = []
```
