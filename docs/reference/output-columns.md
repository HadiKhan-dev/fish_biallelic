# Published report columns

Generated by `python docs/generate_outputs.py` from named column constants and their field descriptions. The [output dictionary](../user/outputs.md) defines row order, missing values, optional files and empty tables. Lists here give the nonempty base schema in order; the pedigree variations below are part of the file contract.

Pedigree regime variations: nonstandard view tables append `regime` (`low_material` or `not_assessable`). Low-material support columns replace `loco` with `lobo`, and `informative_contig_count` becomes `informative_block_count`. The block table is published only for nonstandard regimes (empty for not assessable). Tier A tables are empty in both nonstandard regimes. Standard tables retain their released columns.
