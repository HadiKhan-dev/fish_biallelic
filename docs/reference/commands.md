# Command reference

Generated by `python docs/generate_references.py` from the CLI parser. Options are checked against that parser by the documentation build.

`run CONFIG` initialises a run when needed. Explicit `init` is required before workflow-step commands. Standalone export uses published records and has no source-VCF option. See [workflow mode](../user/workflow.md) for dependencies and markers.

| Argument | Arity | Default | Choices | Help |
|---|---|---|---|---|
| `-h, --help` | 0 | `—` | — | show this help message and exit |

| `--products` | + | `['founders', 'samples']` | founders, samples, tracks | founders: per-contig founder VCF (haploid GT, one column c<component>_H<row> per founder row); samples: phased sample VCF (GT:PS); tracks: per-component founder-track TSV.gz (CHROM POS H0 H1 ...). |
