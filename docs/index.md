# Documentation

Read the [installation guide](user/installation.md), try the
[synthetic quick start](user/quickstart.md), then follow [running a cross](user/running.md).
The [workflow guide](user/workflow.md) gives explicit scatter/gather steps.

The [output dictionary](user/outputs.md) defines public products and missing values.
Check [limitations](user/limitations.md) before interpreting a result.

[Methods](methods/index.md) describe models and ordered decisions. Generated
[settings](reference/settings.md), [scientific parameters](reference/parameters.md),
[commands](reference/commands.md), [record fields](reference/records.md) and
[table columns](reference/output-columns.md), [tie and random conventions](reference/conventions.md)
and [declared kernels](developer/kernels.md) come from the current code.
The [tested environment](reference/environment.md) identifies the reference dependency versions.

Developer documentation covers [architecture](developer/architecture.md),
[contracts](developer/contracts.md), [style](developer/style.md),
[numerical and tie rules](developer/ties.md), [retained accretions](developer/accretions.md),
[costs](developer/costs.md), [testing](developer/testing.md),
[adding a model](developer/adding_a_model.md) and the [glossary](developer/glossary.md).
