# Adding or changing a model

A scientific specification states the question, inputs, assumptions, outputs,
ordered rules, parameters, randomness, tie preferences, costs, approximation
limits and behaviour at empty or invalid inputs. Identify the units and products
whose meaning changes.

Define typed contracts and field roles with explicit sample, site and founder
axes, missingness, units, schemas and view lifetimes. Implement pure transitions
with named parameters, streams, tie policies and declared kernel signatures.

Stage adapters own dependencies, code roots, identities, publication and resource
models. Results readers expose typed products; output writers format those
products without recreating scientific choices. Document current rules, output
fields, costs and limitations beside their implementation.

A model version changes deliberately when candidates, priors, random draws,
thresholds or release rules change. Truth remains separate from inference, and
metadata cannot bypass an unresolved scientific decision.
